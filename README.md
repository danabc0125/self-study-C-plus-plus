# self-study-C++

Motivated by personal interest, I self-studied C++ over a ten-month period during my second year of high school. I built a foundation in local compilation, core syntax, and basic algorithms, and applied these skills by developing several small tools and games.

---

Below are the source code for several basic algorithms I learned, as well as small tools and games I developed:

## Basic Algorithms

- [Binary Search Algorithm](./binary_search.cpp)  
  Efficiently searches for a target value within a sorted array by repeatedly dividing the search interval in half.

- [Dijkstra's Algorithm](./dijkstra's_algorithm.cpp)  
  (One of the most challenging algorithms I have learned so far.)
  Computes the shortest path from a source node to all other nodes in a weighted graph.

- [Quick Sort Algorithm](./quick_sort.cpp)  
  A fast and widely used sorting algorithm based on the divide-and-conquer strategy.

---

## Small Games

- [Tic-Tac-Toe](./tictactoe.cpp)  
  A simple two-player grid-based game implementation demonstrating basic game logic and input handling.

- [1A2B](./1A2B.cpp)  
  A number-guessing game where the system generates a hidden 4-digit number, and the player makes guesses.  
  "A" represents correct digits in the correct position, while "B" represents correct digits in the wrong position.

- [十八骰仔](./十八骰仔.cpp)  
  A simulation of a traditional Taiwanese dice game, implementing random number generation and rule-based scoring.

---

## Small Tools

- [Password Generator](./password_generator.cpp)  
  Generates random passwords based on user-defined criteria, such as the number of digits and special characters.
